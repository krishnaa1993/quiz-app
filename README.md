# Quiz App

A simple Quiz App built using HTML, CSS, and JavaScript.

## Features

- Multiple-choice questions
- Instant Correct/Wrong feedback
- Score tracking
- Next button navigation
- Prevents selecting multiple answers
- Final score display
- Responsive and simple UI

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

Questions are stored as an array of JavaScript objects.

The app dynamically creates answer buttons, checks the selected answer against the correct answer, keeps track of the score, and displays the final result after the last question.
